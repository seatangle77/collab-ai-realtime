# CoI 认知临场感编码手册

请把每条观点单元编码为一个或多个认知临场感阶段。只根据观点原文判断，不补充原文没有表达的信息。

- `TE`（触发事件）：提出问题、困惑、矛盾、意外或需要解决的议题。
- `EX`（探索）：提出想法、举例、搜集信息、交换观点或发散讨论，但尚未形成明确整合。
- `IN`（整合）：连接不同观点、比较权衡、归纳总结、解释关系或形成较完整结论。
- `RE`（解决）：把结论用于实际问题，提出可执行方案、验证方法、决定或应用结果。

编码规则：

1. 一条观点可包含多个明确阶段；只选择原文中确实存在的类别。
2. 不要仅凭关键词判断，要看这句话在表达什么认知活动。
3. 若同时出现探索与整合，只有在明确连接、比较或归纳观点时才选择 `IN`。
4. 只有出现实际应用、行动方案、验证或明确决定时才选择 `RE`。
5. 理由用一到两句中文说明，并引用或概括原文中的直接依据，不评价说话者。
